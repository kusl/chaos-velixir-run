# 0016 AGPL and REUSE

Status: accepted

- AGPL-3.0-or-later, full text in `LICENSE`.
- SPDX headers would be comments, which this project avoids. `REUSE.toml` declares `SPDX-License-Identifier` and `SPDX-FileCopyrightText` for every file instead, which REUSE-aware tools read.
- AGPL section 13: every page links to the source in the footer, and the About page explains the license.
