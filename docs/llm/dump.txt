# chaos-velixir-run

A message board, a shared drawing canvas and a shared slot machine that everyone sees live and nobody keeps. Blazor Server on .NET 10, on the [velixir](https://velixir.net) free plan (0.25 vCPU, 256 MB). Live at https://chaos.velixir.run/.

- Board: the server keeps the newest 50 messages; each browser keeps up to 10,000 in IndexedDB and offers its newest 50 back after a server restart. Dotted border means the server no longer has it.
- Canvas: one black pen on a shared square page, live for everyone, one reset button, lost on restart.
- Slots: one shared machine. A press draws five symbols (A–Z, 0–9) on the server and locks the button for everyone until the reels stop. Three of a kind or a five-symbol straight wins. Results are kept like board messages. Ten successful presses unlock auto spin.
- No third-party code, no cookies, no accounts. Strict CSP with no inline scripts.

## Requirements

- .NET SDK 10.0.100 or later in the 10.0 band
- Node.js 22 or later (JavaScript tests)
- Podman 4 or later (end-to-end tests)

## Commands

```
dotnet run --project src/Chaos.Web
scripts/run-all.sh [--skip-e2e] [--skip-js] [--skip-export]
```

`run-all.sh` builds with warnings as errors, runs the .NET and JavaScript tests with coverage, runs Playwright in Podman, then writes `docs/llm/dump.txt`. Output lands in `artifacts/`. Exit code 2 is a usage error, 127 a missing tool.

## Layout

| Path | What |
| --- | --- |
| `src/Chaos.Web` | The app. The only folder velixir builds. |
| `tests/Chaos.Web.Tests` | xUnit v3 unit and integration tests |
| `tests/Chaos.E2E` | Playwright tests, run in Podman |
| `tests/js` | Vitest tests for the hand-written modules |
| `scripts` | Build, test and export scripts |
| `docs/adr` | Architecture decision records |

## Deploy

Every push to `main` runs `.github/workflows/velixir.yml`, which uploads `src/Chaos.Web` only. It needs the `VELIXIR_API_KEY` repository secret. Every push also runs `.github/workflows/ci.yml`. Turn on the HTTP health probe (`/health`) under Scaling, Runtime in velixir.

Limits can be changed without a rebuild through environment variables, for example `Chaos__MaxConnections=60`. See `src/Chaos.Web/Infrastructure/ChaosOptions.cs`.

# 0002 Static SSR with interactive islands

Status: accepted

- Every page is static server-side rendering. Navigation uses Blazor enhanced navigation and needs no circuit.
- `/board`, `/canvas` and `/slots` each host one `InteractiveServer` island (`BoardIsland`, `CanvasIsland`, `SlotIsland`). Only they open a circuit. Blazor closes the circuit when no island remains on the page.
- The board and slots feeds are rendered by the static page and then owned by the island's JavaScript module. It is marked `data-permanent` so enhanced navigation does not overwrite it. Up to 10,000 local messages never enter a server render tree.
- The compose form and the reset button are Blazor-rendered. Drawing, IndexedDB and the slot machine controls are JavaScript; `SlotIsland` renders its markup once and never re-renders.
- No bUnit: components are thin; logic lives in services tested directly, and the pages are covered by integration and Playwright tests.

# 0003 Deploy only the web project

Status: accepted

velixir builds with a Nixpacks-style plan: `dotnet restore` and `dotnet publish -c Release -o out` at the upload root, then starts `./out/<first csproj>`. Uploading the repository root would restore, build and publish the test projects too, including the Playwright driver, onto a 1 GB disk.

- The deploy workflow runs `velixir deploy --app <id> --source-dir ./src/Chaos.Web`, the documented monorepo option.
- `Chaos.Web.csproj` is self-sufficient: target framework, nullable, implicit usings and runtime settings are in the project, not only in `Directory.Build.props`. `global.json`, central package management and analyzers do not reach the velixir build, which is fine because the project has no package references.
- The start command runs from the upload root, so the content root is the source folder, not `out/`. The web root is set to `wwwroot` next to the assembly when it exists, so published assets are served. The content root is left alone because `WebApplicationFactory` sets it.
- The app binds to `PORT` when set, like zen.
- Deploys are not gated on CI, matching zen. A failing velixir build keeps the previous release; the `/health` probe stops a release that does not start.

# 0004 UUIDv7 ids and handshake rules

Status: accepted

- The server creates every id with `Guid.CreateVersion7` from its own clock. Clients never mint ids. Timestamps are read from the id.
- The id string sorts in time order, so it is also the IndexedDB key and the sort key everywhere. Two posts in the same millisecond sort in random order; that is accepted.
- Handshake: the client offers its 50 newest local messages, newest first, in chunks under 24 KB so no SignalR message exceeds the 32 KB limit. The server considers at most 50 per circuit.
- An offered message is accepted only if its id is a valid UUIDv7, its time is not in the future, its time is before the server started, and its text is already normalized. Then it is merged; the server keeps the newest 50 and keeps its own copy on id ties.
- The start-time rule rejects forged recent messages: anything stamped after the server started came from this server, so if the server does not have it, it is forged or already evicted. It costs posts made to an old instance during a rolling deploy; those stay in local history.
- Posts: 500 UTF-16 code units after normalization, cut on grapheme boundaries; the same text as one of the 10 newest messages is refused.

# 0005 IndexedDB local history

Status: accepted

- Database `chaos-board`, store `messages`, key path `id`, values `{ id, text }`. Slots use `chaos-slots`, store `spins`, values `{ id, text, mine }`, through the same `LocalHistory` exported by `BoardIsland.razor.js`.
- Schema changes are numbered migrations in `BoardIsland.razor.js`; `onupgradeneeded` runs every step from the stored version. A database from a newer schema (`VersionError`) is deleted and recreated, since the server can refill it.
- Other tabs close their connection on `versionchange`, so upgrades and deletes are not blocked for long.
- Cap: 10,000 messages. After each write, the oldest are deleted with one key-range delete.
- The feed shows the server window plus 100 archived messages, with a button for 100 more. Items use `content-visibility: auto`.
- Live messages have a solid border, messages the server no longer has a dotted one.
- The About page deletes both databases and the slot press count without touching the theme. The next visit to the board recreates it from the server snapshot.
- If IndexedDB is unavailable the board still works, without history.

# 0006 Canvas coordinates, epochs and storage

Status: accepted

- The page is square (`aspect-ratio: 1`). Points are normalized to 0–1 and sent as integers 0–4095. The brush width is 0.6% of the canvas side, so every device draws the same picture.
- The backing store is CSS size times `devicePixelRatio`. A `ResizeObserver` and a `resolution` media query trigger a full redraw from stored points.
- Input: pointer events with pointer capture, `touch-action: none`, primary pointer only, left mouse button only, coalesced events when available, points closer than 3 units dropped.
- Palm rejection: touches wider or taller than 40 CSS px are ignored, and so is any touch within 1.5 s of pen input.
- Batches go out every 50 ms, at most 256 points, one call in flight. A stroke ends at 2,000 points.
- Every reset increments an epoch. Batches tagged with an old epoch are refused, so strokes in flight during a reset vanish.
- Late joiners get a snapshot of every stored stroke. The store keeps 20,000 points and evicts the oldest finished strokes first. Clients that already drew an evicted stroke keep showing it until the next reset.
- Strokes live only in memory and are lost on restart.

# 0007 Per-client outboxes over the circuit

Status: accepted

- Transport is the Blazor circuit itself: JS calls `[JSInvokable]` methods, the server calls the module's `apply`. No separate SignalR hub and no extra JavaScript client.
- Each island owns a bounded channel (`Outbox<T>`) drained by one pump that sends batches in order and waits for the browser to finish each batch. A full outbox, a failed call or a 20 s stall drops the subscriber.
- Subscribing enqueues a snapshot under the same lock as updates, so nothing is missed or duplicated.
- Board deltas carry `version` and `previous`; a gap triggers a fresh snapshot. Canvas updates carry an offset per stroke; a gap triggers a fresh snapshot.
- The browser pings every 25 s and resubscribes when the server says it was dropped, and resubscribes after every reconnect.

# 0008 Rate and connection limits

Status: accepted

Defaults live in `ChaosOptions` and can be overridden with `Chaos__*` environment variables. velixir's edge limits sit in front of these.

| Limit | Default |
| --- | --- |
| HTTP requests per client | 120 burst, 10 per second |
| WebSocket connections per client | 8 |
| WebSocket connections in total | 80, then 503 |
| Posts per client | 3 burst, 1 every 2 s |
| Message length | 500 |
| Offered messages per circuit | 50 |
| Stroke points per circuit | 4,000 burst, 1,500 per second |
| Points per batch / stroke / canvas | 256 / 2,048 / 20,000 |
| Resets | 1 s global cooldown, 2 burst per client |
| Slot presses | one spin at a time (4 s), 3 burst, 1 every 2 s per client |
| Slot results kept | 50 |

- A client is its IP after `X-Forwarded-For`, or its /64 for IPv6.
- The hub (`/_blazor`) only accepts WebSocket connections, so connection counts are real. Clients behind proxies that block WebSockets cannot use the board, canvas or slots.
- The total cap protects the 256 MB container: zen ran out of memory near 100 circuits.
- In-circuit limits use a `TimeProvider` token bucket so tests are deterministic. HTTP limits use ASP.NET Core's rate limiter.
- A press during a spin is refused before the per-client bucket, so waiting players are not penalized.
- There is no moderation. The About page says plainly that content spreads to every client and cannot be recalled.

- `Blazor.start` is called from `App.razor.js`, not an inline script. The reconnect UI is our own element, so Blazor injects no styles. No markup uses `style` attributes.

- `/_blazor` requests with an `Origin` header must match the request host or `Chaos:AllowedOrigins`. Requests without `Origin` pass, since only browsers can be tricked into cross-site WebSockets.
- Headers are set in `OnStarting` so error pages keep them.

# 0012 Reconnect, backoff, cold start

Status: accepted

# 0019 Shared slot machine

Status: accepted

- `/slots` hosts `SlotIsland`. Results are `{ id, text }` like board messages: UUIDv7 from the server clock, five symbols from `0-9A-Z`, newest 50 kept, same offer, merge and delta rules (`MessageWindow`).
- The server draws the result with `RandomNumberGenerator` when it accepts a press, then refuses every press until `SpinMilliseconds` (default 4,000) has passed. Busy presses are checked before the per-client bucket.
- The accepting delta and late-joiner snapshots carry `spin: { id, remaining }`. Clients animate for `remaining` ms from receipt, then add the result to the feed. Because receipt is later than the server clock, a client's button only re-enables after the server lock has expired.
- A spin that arrives while an older animation runs finishes the older one at once.
- Winners: three or more of one symbol anywhere, or five strictly ascending or descending in ASCII order (digits before letters). About 1 in 50. Rules exist in `SlotRules.cs` and `SlotIsland.razor.js`; both are tested with the same cases.
- No identity. `Press` returns the new id, `busy` or `slow` to the caller only. The browser marks its own results as `mine` in IndexedDB.
- Successful presses are counted in `localStorage` (`chaos-slots-presses`). At 10 the auto spin toggle appears; it presses 200–1,000 ms after each settle, pauses while the tab is hidden, and is off on every page load.
- Reels are DOM strips moved with the Web Animations API by percentage of their own height, so no layout reads. Reduced motion swaps symbols without movement. Nothing uses inline style attributes, so the CSP is unchanged.

set -euo pipefail

INCLUDE_NAMES=".gitignore .gitattributes .editorconfig"
EXCLUDE_NAMES="package-lock.json LICENSE"
EXCLUDE_DIRS="bin obj .vs .git node_modules .vscode .idea TestResults artifacts coverage .velixir"
EXCLUDE_PREFIXES="docs/llm/"

PROJECT_PATH="$(cd "$PROJECT_PATH" && pwd)"
cd "$PROJECT_PATH"

case "$OUTPUT_FILE" in
    /*) OUTPUT_PATH="$OUTPUT_FILE" ;;
    *)  OUTPUT_PATH="$PROJECT_PATH/$OUTPUT_FILE" ;;
esac
OUTPUT_DIR="$(dirname "$OUTPUT_PATH")"
mkdir -p "$OUTPUT_DIR"

OUTPUT_REL="${OUTPUT_PATH#"$PROJECT_PATH"/}"

if [ -t 1 ]; then
    GREEN='\033[0;32m'; YELLOW='\033[0;33m'; CYAN='\033[0;36m'; NC='\033[0m'
else
    GREEN=''; YELLOW=''; CYAN=''; NC=''
fi
log() { printf "%b%s%b\n" "$1" "$2" "$NC"; }

sha256_of() {
    if command -v sha256sum >/dev/null 2>&1; then
        sha256sum "$1" | awk '{print $1}'
    elif command -v shasum >/dev/null 2>&1; then
        shasum -a 256 "$1" | awk '{print $1}'
    else
        printf 'unavailable'
    fi
}

mod_time_utc_of() {
    local epoch
    if epoch="$(stat -c '%Y' "$1" 2>/dev/null)"; then
        date -u -d "@$epoch" '+%Y-%m-%d %H:%M:%S'
    else
        epoch="$(stat -f '%m' "$1")"
        date -u -r "$epoch" '+%Y-%m-%d %H:%M:%S'
    fi
}

line_count_of() {
    awk 'END { print NR }' "$1"
}

is_included_file() {
    local name="${1##*/}" ext entry
    for entry in $EXCLUDE_NAMES; do
        [ "$name" = "$entry" ] && return 1
    done
    case "$name" in
        .env|.env.*) return 1 ;;
    esac
    for entry in $INCLUDE_NAMES; do
        [ "$name" = "$entry" ] && return 0
    done
    ext="${name##*.}"
    [ "$ext" != "$name" ] || return 1
    ext="$(printf '%s' "$ext" | tr '[:upper:]' '[:lower:]')"
    for entry in $INCLUDE_EXTENSIONS; do
        [ "$ext" = "$entry" ] && return 0
    done
    return 1
}

is_excluded_path() {
    local path="$1" entry
    for entry in $EXCLUDE_PREFIXES; do
        case "$path" in
            "$entry"*) return 0 ;;
        esac
    done
    for entry in $EXCLUDE_DIRS; do
        case "$path" in
            "$entry"/*|*/"$entry"/*) return 0 ;;
        esac
    done
    return 1
}

is_text() {
    [ ! -s "$1" ] || grep -Iq . "$1"
}

in_git_repo() { git rev-parse --is-inside-work-tree >/dev/null 2>&1; }

render_tree() {
    local -a parts prev
    local rel n common i j indent
    prev=()
    echo "."
    while IFS= read -r -d '' rel; do
        IFS='/' read -r -d '' -a parts < <(printf '%s\0' "$rel") || true
        n=${#parts[@]}

        common=0
        while [ "$common" -lt $((n - 1)) ] && [ "$common" -lt "${#prev[@]}" ] \
              && [ "${parts[$common]}" = "${prev[$common]}" ]; do
            common=$((common + 1))
        done

        for ((i = common; i < n; i++)); do
            indent="    "
            for ((j = 0; j < i; j++)); do indent="$indent    "; done
            if [ "$i" -lt $((n - 1)) ]; then
                printf '%s%s/\n' "$indent" "${parts[$i]}"
            else
                printf '%s%s\n' "$indent" "${parts[$i]}"
            fi
        done

        if [ "$n" -gt 1 ]; then
            prev=("${parts[@]:0:$((n - 1))}")
        else
            prev=()
        fi
    done < "$FILE_LIST"
}

    if (attempt <= 0) {

        }
    };

export function chunkOffers(messages, maxBytes = OFFER_BYTES, limit = OFFER_LIMIT) {
    const encoder = new TextEncoder();
    const chunks = [];
    let chunk = [];
    let size = 0;
    for (const message of messages.slice(0, limit)) {
        const bytes = encoder.encode(message.id).length + encoder.encode(JSON.stringify(message.text)).length + 8;
        if (bytes > maxBytes) {
            continue;
        }
        if (chunk.length > 0 && size + bytes > maxBytes) {
            chunks.push(chunk);
            chunk = [];
            size = 0;
        }
        chunk.push(message);
        size += bytes;
    }
    if (chunk.length > 0) {
        chunks.push(chunk);
    }
    return chunks;
}

export function openDatabase(factory, schema = SCHEMA, onClose = () => {}, allowReset = true) {
    return new Promise((resolve, reject) => {
        const request = factory.open(schema.name, schema.version);
        request.onupgradeneeded = event => upgrade(request.result, event.oldVersion, event.newVersion ?? schema.version, schema.migrations);
        request.onsuccess = () => {
            const db = request.result;
            db.onversionchange = () => {
                db.close();
                onClose();
            };
            db.onclose = onClose;
            resolve(db);
        };
        request.onerror = event => {
            if (allowReset && request.error?.name === 'VersionError') {
                event.preventDefault();
                deleteDatabase(factory, schema.name)
                    .then(() => openDatabase(factory, schema, onClose, false))
                    .then(resolve, reject);
                return;
            }
            reject(request.error);
        };
    });
}

                }
                if (items.length >= limit) {
                    done = false;
                    resolve();
                    return;
                }
                last = cursor.key;
                if (!skip.has(cursor.key)) {
                    items.push(cursor.value);
                }
                cursor.continue();
            };
            request.onerror = () => reject(request.error);
        });
        return { items, last, done };
    }

    async save(messages) {
        const db = await this.database();
        if (!db || messages.length === 0) {
            return;
        }
        const transaction = db.transaction(this.schema.store, 'readwrite');
        const done = finished(transaction);
        const store = transaction.objectStore(this.schema.store);
        for (const message of messages) {
            store.put(message);
        }
        const excess = excessOf(await settle(store.count()), this.schema.cap);
        if (excess > 0) {
            const keys = await settle(store.getAllKeys(null, excess));
            store.delete(IDBKeyRange.upperBound(keys[keys.length - 1]));
        }
        await done;
    }
}

class BoardClient {
    constructor(dotnet, doc, win) {
        this.dotnet = dotnet;
        this.doc = doc;
        this.win = win;
        this.history = new LocalHistory(win.indexedDB);
        this.feed = doc.getElementById('board-feed');
        this.empty = doc.getElementById('board-empty');
        this.older = doc.getElementById('board-older');
        this.announcer = doc.getElementById('board-announcer');
        this.textarea = doc.getElementById('compose-text');
        this.version = -1;
        this.live = new Map();
        this.shown = new Map();
        this.cursor = null;
        this.joining = null;
        this.timer = 0;
        this.disposed = false;
        this.onKeyDown = event => this.keyDown(event);
        this.onOlder = () => this.loadOlder();
        this.onReconnected = () => this.join();
    }

    async start() {
        this.textarea?.addEventListener('keydown', this.onKeyDown);
        this.older?.addEventListener('click', this.onOlder);
        this.win.addEventListener('chaos:reconnected', this.onReconnected);
        this.timer = this.win.setInterval(() => this.ping(), PING_MS);
        try {
            await this.offer();
        } catch {
        }
        await this.join();
    }

    keyDown(event) {
        if (event.key !== 'Enter' || !(event.ctrlKey || event.metaKey)) {
            return;
        }
        event.preventDefault();
        this.textarea.dispatchEvent(new this.win.Event('change', { bubbles: true }));
        this.textarea.form?.requestSubmit();
    }

    async offer() {
        const local = await this.history.newest(OFFER_LIMIT);
        for (const chunk of chunkOffers(local)) {
            if (this.disposed) {
                return;
            }
            await this.dotnet.invokeMethodAsync('Offer', chunk.map(message => message.id), chunk.map(message => message.text));
        }
    }

    join() {
        if (this.disposed) {
            return Promise.resolve();
        }
        this.version = -1;
        this.joining ??= this.dotnet.invokeMethodAsync('Join')
            .catch(() => {})
            .finally(() => {
                this.joining = null;
            });
        return this.joining;
    }

    async ping() {
        if (this.disposed || this.joining) {
            return;
        }
        try {
            if (!(await this.dotnet.invokeMethodAsync('Ping'))) {
                await this.join();
            }
        } catch {
        }
    }

    async apply(updates) {
        for (const update of updates) {
            if (this.disposed) {
                return;
            }
            if (update.kind === 'snapshot') {
                await this.snapshot(update);
            } else if (update.kind === 'delta' && this.version >= 0) {
                if (needsResync(this.version, update)) {
                    this.join();
                    return;
                }
                await this.delta(update);
            }
        }
    }

    async snapshot(update) {
        this.version = update.version;
        this.live = new Map(update.added.map(message => [message.id, message]));
        try {
            await this.history.save(update.added.map(message => ({ id: message.id, text: message.text })));
        } catch {
        }
        let archive = { items: [], last: null, done: true };
        try {
            archive = await this.history.page(null, PAGE_SIZE, this.live);
        } catch {
        }
        this.cursor = archive.last;
        this.render([...update.added, ...archive.items].sort(newestFirst), archive.done);
    }

    async delta(update) {
        this.version = update.version;
        for (const id of update.removed) {
            this.live.delete(id);
            this.shown.get(id)?.classList.add('archived');
        }
        const fresh = [];
        for (const message of update.added) {
            this.live.set(message.id, message);
            const existing = this.shown.get(message.id);
            if (existing) {
                existing.classList.remove('archived');
            } else {
                this.insert(message, true);
                fresh.push(message);
            }
        }
        this.updateEmpty();
        this.announce(fresh);
        try {
            await this.history.save(update.added.map(message => ({ id: message.id, text: message.text })));
        } catch {
        }
    }

    async loadOlder() {
        if (!this.older) {
            return;
        }
        this.older.disabled = true;
        try {
            const archive = await this.history.page(this.cursor, PAGE_SIZE, this.live);
            this.cursor = archive.last ?? this.cursor;
            for (const message of archive.items) {
                if (!this.shown.has(message.id)) {
                    this.insert(message, false);
                }
            }
            this.older.hidden = archive.done;
        } catch {
            this.older.hidden = true;
        } finally {
            this.older.disabled = false;
        }
    }

    item(message, fresh) {
        const element = this.doc.createElement('li');
        element.className = 'msg';
        element.classList.toggle('archived', !this.live.has(message.id));
        element.classList.toggle('fresh', fresh);
        element.dataset.id = message.id;
        const time = this.doc.createElement('time');
        time.dateTime = isoOf(message.id);
        time.textContent = labelOf(message.id);
        const text = this.doc.createElement('p');
        text.textContent = message.text;
        element.append(time, text);
        return element;
    }

    insert(message, fresh) {
        const element = this.item(message, fresh);
        let next = this.feed.firstElementChild;
        while (next && next.dataset.id > message.id) {
            next = next.nextElementSibling;
        }
        this.feed.insertBefore(element, next);
        this.shown.set(message.id, element);
    }

    render(messages, done) {
        this.shown.clear();
        const fragment = this.doc.createDocumentFragment();
        for (const message of messages) {
            const element = this.item(message, false);
            this.shown.set(message.id, element);
            fragment.append(element);
        }
        this.feed.replaceChildren(fragment);
        if (this.older) {
            this.older.hidden = done;
        }
        this.updateEmpty();
    }

    announce(messages) {
        if (!this.announcer || messages.length === 0) {
            return;
        }
        const newest = [...messages].sort(newestFirst)[0];
        this.announcer.textContent = `New message: ${newest.text.slice(0, 140)}`;
    }

    updateEmpty() {
        if (this.empty) {
            this.empty.hidden = this.shown.size > 0;
        }
    }

    dispose() {
        this.disposed = true;
        this.win.clearInterval(this.timer);
        this.textarea?.removeEventListener('keydown', this.onKeyDown);
        this.older?.removeEventListener('click', this.onOlder);
        this.win.removeEventListener('chaos:reconnected', this.onReconnected);
    }
}

    client.start();
    return {
        apply: updates => client.apply(updates),
        dispose: () => client.dispose(),
    };
}

export const RESOLUTION = 4095;
export const BRUSH = 0.006;
export const FLUSH_MS = 50;
export const MAX_BATCH = 256;
export const MAX_STROKE = 2000;
export const MIN_STEP = 3;
export const PALM_SIZE = 40;
export const PEN_GRACE_MS = 1500;
export const PING_MS = 25000;

export const Result = Object.freeze({
    Accepted: 0,
    Stale: 1,
    TooFast: 2,
    Invalid: 3,
    Full: 4,
    TooLong: 5,
});

export function quantize(value) {
    return Math.round(Math.min(1, Math.max(0, value)) * RESOLUTION);
}

export function toPoint(clientX, clientY, rect) {
    return [quantize((clientX - rect.left) / rect.width), quantize((clientY - rect.top) / rect.height)];
}

export function farEnough(points, x, y, minStep = MIN_STEP) {
    const length = points.length;
    if (length < 2) {
        return true;
    }
    return Math.hypot(x - points[length - 2], y - points[length - 1]) >= minStep;
}

export function isPalm(event, lastPenAt, now) {
    if (event.pointerType !== 'touch') {
        return false;
    }
    if (now - lastPenAt < PEN_GRACE_MS) {
        return true;
    }
    return event.width > PALM_SIZE || event.height > PALM_SIZE;
}

export function backingSize(cssSize, ratio) {
    return Math.max(1, Math.round(cssSize * ratio));
}

export function brushWidth(size) {
    return Math.max(1, size * BRUSH);
}

export function unseen(have, offset, points) {
    if (offset > have) {
        return null;
    }
    const skip = (have - offset) * 2;
    return skip >= points.length ? [] : points.slice(skip);
}

export function drawPath(context, size, points, from) {
    if (points.length === 0 || from >= points.length) {
        return;
    }
    const scale = size / RESOLUTION;
    context.beginPath();
    if (points.length === 2) {
        context.arc(points[0] * scale, points[1] * scale, context.lineWidth / 2, 0, Math.PI * 2);
        context.fill();
        return;
    }
    const start = Math.max(0, from - 2);
    context.moveTo(points[start] * scale, points[start + 1] * scale);
    for (let index = start + 2; index < points.length; index += 2) {
        context.lineTo(points[index] * scale, points[index + 1] * scale);
    }
    context.stroke();
}

class CanvasClient {
    constructor(canvas, dotnet, win) {
        this.canvas = canvas;
        this.dotnet = dotnet;
        this.win = win;
        this.context = canvas.getContext('2d');
        this.epoch = 0;
        this.size = 0;
        this.strokes = new Map();
        this.localId = 0;
        this.active = null;
        this.queue = [];
        this.sending = false;
        this.flushTimer = 0;
        this.lastPenAt = -Infinity;
        this.joining = null;
        this.timer = 0;
        this.observer = null;
        this.ratioQuery = null;
        this.disposed = false;
        this.handlers = {
            pointerdown: event => this.down(event),
            pointermove: event => this.move(event),
            pointerup: event => this.up(event),
            pointercancel: event => this.up(event),
            lostpointercapture: event => this.up(event),
            contextmenu: event => event.preventDefault(),
            contextrestored: () => this.redraw(),
        };
        this.onRatio = () => {
            this.watchRatio();
            this.resize();
        };
        this.onReconnected = () => this.join();
    }

    start() {
        for (const [name, handler] of Object.entries(this.handlers)) {
            this.canvas.addEventListener(name, handler);
        }
        this.observer = new this.win.ResizeObserver(() => this.resize());
        this.observer.observe(this.canvas);
        this.watchRatio();
        this.win.addEventListener('chaos:reconnected', this.onReconnected);
        this.timer = this.win.setInterval(() => this.ping(), PING_MS);
        this.resize();
        this.join();
    }

    watchRatio() {
        this.ratioQuery?.removeEventListener('change', this.onRatio);
        this.ratioQuery = this.win.matchMedia(`(resolution: ${this.win.devicePixelRatio || 1}dppx)`);
        this.ratioQuery.addEventListener('change', this.onRatio);
    }

    resize() {
        const width = this.canvas.getBoundingClientRect().width;
        if (width === 0) {
            return;
        }
        const size = backingSize(width, this.win.devicePixelRatio || 1);
        if (size === this.size) {
            return;
        }
        this.size = size;
        this.canvas.width = size;
        this.canvas.height = size;
        this.redraw();
    }

    prepare() {
        this.context.lineWidth = brushWidth(this.size);
        this.context.lineCap = 'round';
        this.context.lineJoin = 'round';
        this.context.strokeStyle = '#000';
        this.context.fillStyle = '#000';
    }

    redraw() {
        this.prepare();
        this.context.clearRect(0, 0, this.canvas.width, this.canvas.height);
        for (const points of this.strokes.values()) {
            drawPath(this.context, this.size, points, 0);
        }
    }

    join() {
        if (this.disposed) {
            return Promise.resolve();
        }
        this.joining ??= this.dotnet.invokeMethodAsync('Join')
            .catch(() => {})
            .finally(() => {
                this.joining = null;
            });
        return this.joining;
    }

    async ping() {
        if (this.disposed || this.joining) {
            return;
        }
        try {
            if (!(await this.dotnet.invokeMethodAsync('Ping'))) {
                await this.join();
            }
        } catch {
        }
    }

    apply(updates) {
        for (const update of updates) {
            if (update.kind === 'snapshot') {
                this.snapshot(update);
            } else if (update.kind === 'reset') {
                this.clear(update.epoch);
            } else if (update.kind === 'stroke') {
                this.remote(update);
            }
        }
    }

    snapshot(update) {
        this.clear(update.epoch);
        for (const stroke of update.strokes ?? []) {
            this.strokes.set(`r${stroke.id}`, [...stroke.points]);
        }
        this.redraw();
        this.canvas.dataset.ready = '';
    }

    clear(epoch) {
        this.epoch = epoch;
        this.strokes.clear();
        this.active = null;
        this.queue = [];
        this.redraw();
    }

    remote(update) {
        if (update.epoch !== this.epoch) {
            return;
        }
        const key = `r${update.stroke}`;
        let points = this.strokes.get(key);
        if (!points) {
            if (update.offset !== 0) {
                this.join();
                return;
            }
            points = [];
            this.strokes.set(key, points);
        }
        const fresh = unseen(points.length / 2, update.offset, update.points);
        if (fresh === null) {
            this.join();
            return;
        }
        if (fresh.length === 0) {
            return;
        }
        const from = points.length;
        points.push(...fresh);
        drawPath(this.context, this.size, points, from);
    }

    down(event) {
        if (this.active || this.epoch === 0 || !event.isPrimary) {
            return;
        }
        if (event.pointerType === 'mouse' && event.button !== 0) {
            return;
        }
        if (event.pointerType === 'pen') {
            this.lastPenAt = event.timeStamp;
        }
        if (isPalm(event, this.lastPenAt, event.timeStamp)) {
            return;
        }
        event.preventDefault();
        this.canvas.setPointerCapture(event.pointerId);
        this.localId += 1;
        const points = [];
        this.strokes.set(`l${this.localId}`, points);
        this.active = { pointerId: event.pointerId, id: this.localId, epoch: this.epoch, points, sent: 0, ended: false };
        this.queue.push(this.active);
        this.add(event);
    }

    move(event) {
        if (!this.active || event.pointerId !== this.active.pointerId) {
            return;
        }
        const samples = typeof event.getCoalescedEvents === 'function' ? event.getCoalescedEvents() : [];
        for (const sample of samples.length > 0 ? samples : [event]) {
            if (!this.active) {
                return;
            }
            this.add(sample);
        }
    }

    up(event) {
        if (this.active && event.pointerId === this.active.pointerId) {
            this.finish();
        }
    }

    add(event) {
        const record = this.active;
        const [x, y] = toPoint(event.clientX, event.clientY, this.canvas.getBoundingClientRect());
        if (!farEnough(record.points, x, y)) {
            return;
        }
        if (record.points.length / 2 >= MAX_STROKE) {
            this.finish();
            return;
        }
        const from = record.points.length;
        record.points.push(x, y);
        drawPath(this.context, this.size, record.points, from);
        this.schedule();
    }

    finish() {
        if (!this.active) {
            return;
        }
        this.active.ended = true;
        this.active = null;
        this.flush();
    }

    schedule() {
        if (this.flushTimer) {
            return;
        }
        this.flushTimer = this.win.setTimeout(() => {
            this.flushTimer = 0;
            this.flush();
        }, FLUSH_MS);
    }

    async flush() {
        if (this.sending || this.disposed) {
            return;
        }
        const record = this.queue[0];
        if (!record) {
            return;
        }
        const total = record.points.length / 2;
        const count = Math.min(MAX_BATCH, total - record.sent);
        const end = record.ended && record.sent + count === total;
        if (count === 0 && !end) {
            return;
        }
        const points = record.points.slice(record.sent * 2, (record.sent + count) * 2);
        this.sending = true;
        let result = Result.Invalid;
        try {
            result = await this.dotnet.invokeMethodAsync('Draw', record.id, record.epoch, points, end);
        } catch {
            result = Result.Invalid;
        } finally {
            this.sending = false;
        }
        if (result === Result.Accepted) {
            record.sent += count;
            if (end) {
                this.drop(record);
            }
        } else {
            this.drop(record);
            if (this.active === record) {
                this.active = null;
            }
            if (result !== Result.Stale) {
                this.join();
            }
        }
        if (this.queue.length > 0) {
            this.schedule();
        }
    }

    drop(record) {
        const index = this.queue.indexOf(record);
        if (index >= 0) {
            this.queue.splice(index, 1);
        }
    }

    dispose() {
        this.disposed = true;
        for (const [name, handler] of Object.entries(this.handlers)) {
            this.canvas.removeEventListener(name, handler);
        }
        this.observer?.disconnect();
        this.ratioQuery?.removeEventListener('change', this.onRatio);
        this.win.removeEventListener('chaos:reconnected', this.onReconnected);
        this.win.clearInterval(this.timer);
        this.win.clearTimeout(this.flushTimer);
    }
}

        dispose: () => client.dispose(),
    };
}

export function isValid(text) {
    return typeof text === 'string' && /^[0-9A-Z]{5}$/.test(text);
}

function tally(text) {
    const counts = new Map();
    for (const symbol of text) {
        counts.set(symbol, (counts.get(symbol) ?? 0) + 1);
    }
    return counts;
}

function ordered(text, direction) {
    for (let index = 1; index < text.length; index += 1) {
        if ((text.charCodeAt(index) - text.charCodeAt(index - 1)) * direction <= 0) {
            return false;
        }
    }
    return true;
}

export function classify(text) {
    if (!isValid(text)) {
        return 'none';
    }
    const most = Math.max(...tally(text).values());
    if (most >= 5) {
        return 'five';
    }
    if (most === 4) {
        return 'four';
    }
    if (most === 3) {
        return 'three';
    }
    if (ordered(text, 1)) {
        return 'up';
    }
    return ordered(text, -1) ? 'down' : 'none';
}

export function hits(text) {
    const win = classify(text);
    if (win === 'none') {
        return Array(LENGTH).fill(false);
    }
    if (win === 'up' || win === 'down') {
        return Array(LENGTH).fill(true);
    }
    const [top] = [...tally(text)].reduce((best, entry) => (entry[1] > best[1] ? entry : best));
    return [...text].map(symbol => symbol === top);
}

export function above(symbol) {
    return SYMBOLS[(SYMBOLS.indexOf(symbol) + 1) % SYMBOLS.length];
}

export function below(symbol) {
    return SYMBOLS[(SYMBOLS.indexOf(symbol) + SYMBOLS.length - 1) % SYMBOLS.length];
}

export function stopTimes(duration, reels = LENGTH) {
    return Array.from({ length: reels }, (_, index) => Math.round(duration * (0.42 + 0.11 * index)));
}

export function stripFor(current, target, spins, random = Math.random) {
    const filler = Array.from({ length: Math.max(0, spins) }, () => SYMBOLS[Math.floor(random() * SYMBOLS.length)]);
    return [above(target), target, below(target), ...filler, above(current), current, below(current)];
}

        { transform: 'translateY(0%)' },
    ];
}

            spin.timers.push(this.win.setTimeout(() => this.stop(spin, index, target), stop));
        });
        spin.timers.push(this.win.setTimeout(() => this.finish(false), duration));
        this.updateControls();
    }

    roll(spin, index, target, time) {
        const strip = this.strips[index];
        const reel = this.reels[index];
        const symbols = stripFor(this.faces[index], target, Math.max(4, Math.round(time / SYMBOL_MS)));
        this.fill(strip, symbols);
        spin.animations.push(strip.animate(spinFrames(symbols.length), { duration: time, fill: 'forwards' }));
        reel.classList.add('blur');
        spin.timers.push(this.win.setTimeout(() => reel.classList.remove('blur'), Math.round(time * 0.72)));
    }

    stop(spin, index, target) {
        if (this.spin !== spin) {
            return;
        }
        const reel = this.reels[index];
        reel.classList.remove('blur', 'stopped');
        this.setFace(index, target);
        for (const animation of spin.animations) {
            if (animation.effect?.target === this.strips[index]) {
                animation.cancel();
            }
        }
        void reel.offsetWidth;
        reel.classList.add('stopped');
    }

    finish(instant) {
        const spin = this.spin;
        if (!spin) {
            return;
        }
        this.spin = null;
        for (const timer of spin.timers) {
            this.win.clearTimeout(timer);
        }
        for (const animation of spin.animations) {
            animation.cancel();
        }
        const text = spin.message.text;
        this.show(text);
        this.machine.classList.remove('spinning');
        const win = classify(text);
        const marks = hits(text);
        this.reels.forEach((reel, index) => reel.classList.toggle('hit', marks[index]));
        this.machine.classList.toggle('win', win !== 'none');
        this.verdict.textContent = LABELS[win] ?? '';
        this.land(spin.message, !instant);
        this.updateControls();
        this.scheduleAuto();
    }

    land(message, fresh) {
        if (!this.shown.has(message.id)) {
            this.insert(message, fresh);
        }
        this.updateEmpty();
        this.announce(message);
        this.save([message]);
    }

    show(text) {
        [...text].forEach((symbol, index) => this.setFace(index, symbol));
        for (const reel of this.reels) {
            reel.classList.remove('blur', 'hit');
        }
    }

    setFace(index, symbol) {
        this.faces[index] = symbol;
        this.fill(this.strips[index], [above(symbol), symbol, below(symbol)]);
    }

    fill(strip, symbols) {
        const fragment = this.doc.createDocumentFragment();
        for (const symbol of symbols) {
            const cell = this.doc.createElement('span');
            cell.textContent = symbol;
            fragment.append(cell);
        }
        strip.replaceChildren(fragment);
    }

    async press(manual) {
        if (!this.ready || this.spin || this.pressing || this.disposed) {
            return;
        }
        this.pressing = true;
        this.updateControls();
        let reply = { kind: 'error', id: null };
        try {
            reply = parseReply(await this.dotnet.invokeMethodAsync('Press'));
        } catch {
        }
        this.pressing = false;
        if (this.disposed) {
            return;
        }
        if (reply.kind === 'accepted') {
            this.markMine(reply.id);
            this.presses += 1;
            try {
                this.win.localStorage.setItem(PRESS_KEY, String(this.presses));
            } catch {
            }
            this.setStatus('Your press worked. This spin is yours.');
        } else if (reply.kind === 'busy') {
            this.setStatus(manual ? 'Someone else pressed first. Wait for the reels to stop.' : '');
        } else if (reply.kind === 'slow') {
            this.setStatus('Slow down a little.');
        } else {
            this.setStatus('Could not reach the server.');
        }
        this.updateControls();
        this.scheduleAuto();
    }

    markMine(id) {
        this.mine.add(id);
        const existing = this.shown.get(id);
        const message = this.live.get(id);
        if (existing && message) {
            const element = this.item(message, existing.classList.contains('fresh'));
            existing.replaceWith(element);
            this.shown.set(id, element);
            this.save([message]);
        }
    }

    toggleAuto() {
        if (this.presses < AUTO_UNLOCK) {
            return;
        }
        this.auto = !this.auto;
        this.setStatus(this.auto ? 'Auto spin is on. It pauses while this tab is hidden.' : 'Auto spin is off.');
        this.updateControls();
        this.scheduleAuto();
    }

    scheduleAuto() {
        this.win.clearTimeout(this.autoTimer);
        this.autoTimer = 0;
        if (!this.auto || !this.ready || this.spin || this.pressing || this.disposed || this.doc.visibilityState !== 'visible') {
            return;
        }
        this.autoTimer = this.win.setTimeout(() => {
            this.autoTimer = 0;
            this.press(false);
        }, autoDelay());
    }

    updateControls() {
        if (this.spinButton) {
            this.spinButton.disabled = !this.ready || this.spin !== null || this.pressing;
        }
        if (this.autoButton) {
            this.autoButton.hidden = this.presses < AUTO_UNLOCK;
            this.autoButton.setAttribute('aria-pressed', String(this.auto));
        }
        if (this.progress) {
            this.progress.textContent = progressText(this.presses);
        }
    }

    setStatus(text) {
        if (this.status) {
            this.status.textContent = text;
        }
    }

    async loadOlder() {
        if (!this.older) {
            return;
        }
        this.older.disabled = true;
        try {
            const archive = await this.history.page(this.cursor, PAGE_SIZE, this.live);
            this.cursor = archive.last ?? this.cursor;
            for (const record of archive.items) {
                if (record.mine) {
                    this.mine.add(record.id);
                }
                if (!this.shown.has(record.id)) {
                    this.insert(record, false);
                }
            }
            this.older.hidden = archive.done;
        } catch {
            this.older.hidden = true;
        } finally {
            this.older.disabled = false;
        }
    }

    item(message, fresh) {
        const win = classify(message.text);
        const marks = hits(message.text);
        const mine = this.mine.has(message.id) || message.mine === true;
        const element = this.doc.createElement('li');
        element.className = 'msg';
        element.classList.toggle('win', win !== 'none');
        element.classList.toggle('mine', mine);
        element.classList.toggle('archived', !this.live.has(message.id));
        element.classList.toggle('fresh', fresh);
        element.dataset.id = message.id;
        const time = this.doc.createElement('time');
        time.dateTime = isoOf(message.id);
        time.textContent = labelOf(message.id);
        const symbols = this.doc.createElement('p');
        symbols.className = 'symbols';
        [...message.text].forEach((symbol, index) => {
            const cell = this.doc.createElement('span');
            cell.textContent = symbol;
            if (marks[index]) {
                cell.className = 'hit';
            }
            symbols.append(cell);
        });
        element.append(time, symbols);
        if (win !== 'none' || mine) {
            const tags = this.doc.createElement('p');
            tags.className = 'tags';
            if (win !== 'none') {
                const badge = this.doc.createElement('strong');
                badge.className = 'badge';
                badge.textContent = LABELS[win];
                tags.append(badge);
            }
            if (mine) {
                const yours = this.doc.createElement('span');
                yours.className = 'yours';
                yours.textContent = 'Your press';
                tags.append(yours);
            }
            element.append(tags);
        }
        return element;
    }

    insert(message, fresh) {
        const element = this.item(message, fresh);
        let next = this.feed.firstElementChild;
        while (next && next.dataset.id > message.id) {
            next = next.nextElementSibling;
        }
        this.feed.insertBefore(element, next);
        this.shown.set(message.id, element);
    }

    render(messages, done) {
        this.shown.clear();
        const fragment = this.doc.createDocumentFragment();
        for (const message of messages) {
            if (message.mine) {
                this.mine.add(message.id);
            }
            const element = this.item(message, false);
            this.shown.set(message.id, element);
            fragment.append(element);
        }
        this.feed.replaceChildren(fragment);
        if (this.older) {
            this.older.hidden = done;
        }
        this.updateEmpty();
    }

    announce(message) {
        if (!this.announcer) {
            return;
        }
        const win = classify(message.text);
        const spelled = [...message.text].join(' ');
        this.announcer.textContent = win === 'none' ? `Result: ${spelled}.` : `Winner! ${spelled}. ${LABELS[win]}.`;
    }

    updateEmpty() {
        if (this.empty) {
            this.empty.hidden = this.shown.size > 0;
        }
    }

    dispose() {
        this.disposed = true;
        this.win.clearInterval(this.timer);
        this.win.clearTimeout(this.autoTimer);
        if (this.spin) {
            for (const timer of this.spin.timers) {
                this.win.clearTimeout(timer);
            }
            for (const animation of this.spin.animations) {
                animation.cancel();
            }
            this.spin = null;
        }
        this.spinButton?.removeEventListener('click', this.onSpin);
        this.autoButton?.removeEventListener('click', this.onAuto);
        this.older?.removeEventListener('click', this.onOlder);
        this.win.removeEventListener('chaos:reconnected', this.onReconnected);
        this.doc.removeEventListener('visibilitychange', this.onVisibility);
    }
}

export function attach(machine, dotnet) {
    const client = new SlotClient(machine, dotnet, document, window);
    client.start();
    return {
        apply: updates => client.apply(updates),
        dispose: () => client.dispose(),
    };
}

@page "/about"

<PageTitle>About chaos</PageTitle>

<h1>About</h1>
<p class="lede">Chaos is a small public experiment: a message board, a drawing canvas and a slot machine that anyone can use, with no accounts and nothing kept for long.</p>

<h2>Why it exists</h2>
<p>To show how much a plain Blazor Server app can do on a free hosting plan with a quarter of a CPU and 256 MB of memory, with no database, no cookies and no third-party code. The HTML, the CSS and the small amount of JavaScript are all written by hand.</p>

<h2>What you can do</h2>
<dl>
    <dt><a href="board">Board</a></dt>
    <dd>Post a message of up to 500 characters. Everyone on the board sees it at once. The server keeps the newest 50. This browser keeps up to 10,000 on your device, so you still see messages after the server has forgotten them. Those have a dotted border.</dd>
    <dt><a href="canvas">Canvas</a></dt>
    <dd>Draw with a mouse, a finger or a stylus. Everyone sees each stroke as it is drawn. Anyone can reset the page for everyone, and a server restart clears it too.</dd>
    <dt><a href="slots">Slots</a></dt>
    <dd>Press the button and the shared machine spins for everyone watching. Nobody can press again until the reels stop, and then whoever presses first goes next. Nobody knows who pressed, but you are told whether your own press worked. After ten successful presses from this browser you get an auto spin button that presses for you each time the reels stop. No money or prizes are involved; it is just for fun.</dd>
</dl>

<h2>Winners</h2>
<p>Each spin is five symbols, each one of the letters A to Z or the digits 0 to 9. A spin is a winner if:</p>
<ul>
    <li><strong>Three, four or five of a kind:</strong> the same symbol appears at least three times, anywhere. <code>7Q7A7</code> wins.</li>
    <li><strong>Straight up or down:</strong> all five symbols climb or all five fall, with no repeats, in the order 0 to 9 and then A to Z. <code>13AKZ</code> and <code>ZKA80</code> win; <code>ZK8A0</code> does not.</li>
</ul>
<p>Winners have a gold border and a star badge in the results, and their winning symbols are highlighted. About one spin in fifty wins.</p>

<h2>How it works</h2>
<ul>
    <li>Pages are rendered on the server and arrive as plain HTML. Only the board, the canvas and the slot machine open a live connection, over a WebSocket.</li>
    <li>Every message and every spin gets a UUIDv7 from the server clock, so its ID also records when it happened. Anything that claims to come from the future is rejected.</li>
    <li>The server can restart at any time and then remembers nothing. When you open the board or the slots, your browser offers its 50 newest entries back, and the server keeps the ones that fit among its newest 50.</li>
    <li>The canvas sends strokes in small batches of points measured from 0 to 1 across a square page, so phones and desktops draw the same picture. Each reset starts a new round, and strokes still in flight from the old one are dropped.</li>
    <li>The slot result is drawn on the server with a cryptographic random number generator the moment a press is accepted. The server then refuses every press until the spin time has passed, so only one spin runs at a time. Your browser plays the reels for the time the server says is left, then adds the result to the list; your own button stays off until your reels stop, so a spin always settles on your screen before you can press again.</li>
    <li>The reels are plain HTML animated with the Web Animations API. If your device asks for reduced motion, the symbols change without spinning.</li>
    <li>A strict Content Security Policy only allows scripts, styles and connections from this site. There are no inline scripts.</li>
</ul>

<h2>Before you post</h2>
<p class="warning">Anything you post or draw goes to every connected browser at once and is stored on their devices. It can't be edited, deleted or recalled. Nothing is moderated. Don't share anything private.</p>

<h2>Your data</h2>
<p>There are no accounts, no cookies and no tracking. Your theme choice and your count of successful slot presses are kept in this browser's local storage. Board messages and slot results are kept in this browser's IndexedDB, up to 10,000 of each, with the oldest removed first. Results you started are marked as yours only in this browser.</p>
<p class="clear">
    <button type="button" data-clear-history="clear-status">Clear local history</button>
    <output id="clear-status"></output>
</p>
<p>This removes the board and slot history and your press count on this device. The next time you open the board or the slots, they fill up again from the server.</p>

<p>The code is on <a href="https://github.com/kusl/chaos-velixir-run">GitHub</a> under the GNU Affero General Public License, version 3 or later. If you run a modified copy for other people, you have to offer them its source too.</p>

using Chaos.Web.Infrastructure;
using Microsoft.Extensions.Options;

namespace Chaos.Web.Drawing;

internal sealed class CanvasService
{
    public const int MaxCoordinate = 4095;
    public const int MaxBatchPoints = 256;
    public const int MaxStrokePoints = 2048;

    public static readonly TimeSpan ResetCooldown = TimeSpan.FromSeconds(1);

    private readonly TimeProvider _time;
    private readonly int _maxPoints;
    private readonly double _pointBurst;
    private readonly double _pointsPerSecond;
    private readonly KeyedTokenBuckets _resets;
    private readonly Lock _gate = new();
    private readonly LinkedList<Stroke> _strokes = new();
    private readonly HashSet<ICanvasSubscriber> _subscribers = [];
    private int _epoch = 1;
    private long _nextStroke;
    private int _points;
    private long? _lastReset;

    public CanvasService(TimeProvider time, IOptions<ChaosOptions> options)
    {
        ArgumentNullException.ThrowIfNull(time);
        ArgumentNullException.ThrowIfNull(options);
        var limits = options.Value;
        _time = time;
        _maxPoints = limits.CanvasMaxPoints;
        _pointBurst = limits.StrokePointBurst;
        _pointsPerSecond = limits.StrokePointsPerSecond;
        _resets = new KeyedTokenBuckets(limits.ResetBurst, limits.ResetsPerSecond, time);
    }

    public int Epoch
    {
        get
        {
            lock (_gate)
            {
                return _epoch;
            }
        }
    }

    public int PointCount
    {
        get
        {
            lock (_gate)
            {
                return _points;
            }
        }
    }

    public int StrokeCount
    {
        get
        {
            lock (_gate)
            {
                return _strokes.Count;
            }
        }
    }

    public CanvasSession OpenSession(ICanvasSubscriber subscriber) =>
        new(subscriber, new TokenBucket(_pointBurst, _pointsPerSecond, _time));

    public DrawResult Draw(CanvasSession session, int epoch, int clientStroke, int[] points, bool end)
    {
        ArgumentNullException.ThrowIfNull(session);
        ArgumentNullException.ThrowIfNull(points);

        if (points.Length % 2 != 0 || points.Length > MaxBatchPoints * 2 || (points.Length == 0 && !end))
        {
            return DrawResult.Invalid;
        }

        foreach (var value in points)
        {
            if ((uint)value > MaxCoordinate)
            {
                return DrawResult.Invalid;
            }
        }

        var count = points.Length / 2;
        lock (_gate)
        {
            if (epoch != _epoch)
            {
                return DrawResult.Stale;
            }

            var stroke = session.Open is { } open && open.Epoch == _epoch && open.ClientId == clientStroke ? open : null;
            if (stroke is null)
            {
                if (clientStroke <= session.LastClientId || count == 0)
                {
                    return DrawResult.Invalid;
                }
            }
            else if (stroke.Count + count > MaxStrokePoints)
            {
                FinishOpen(session);
                return DrawResult.TooLong;
            }

            if (!session.Bucket.TryTake(count))
            {
                return DrawResult.TooFast;
            }

            if (!MakeRoom(count))
            {
                return DrawResult.Full;
            }

            if (stroke is null)
            {
                FinishOpen(session);
                stroke = new Stroke(++_nextStroke, _epoch, clientStroke);
                _strokes.AddLast(stroke);
                session.Open = stroke;
                session.LastClientId = clientStroke;
            }

            var offset = stroke.Count;
            stroke.Append(points);
            _points += count;
            if (end)
            {
                stroke.Done = true;
                session.Open = null;
            }

            Broadcast(CanvasUpdate.ForStroke(_epoch, stroke.Id, offset, points, end), session.Subscriber);
            return DrawResult.Accepted;
        }
    }

    public ResetResult Reset(string client)
    {
        lock (_gate)
        {
            var now = _time.GetTimestamp();
            if (_lastReset is { } last && _time.GetElapsedTime(last, now) < ResetCooldown)
            {
                return ResetResult.TooFast;
            }

            if (!_resets.TryTake(client))
            {
                return ResetResult.TooFast;
            }

            _lastReset = now;
            _epoch++;
            _strokes.Clear();
            _points = 0;
            Broadcast(CanvasUpdate.ForReset(_epoch), null);
            return ResetResult.Accepted;
        }
    }

    public void Abandon(CanvasSession session)
    {
        ArgumentNullException.ThrowIfNull(session);
        lock (_gate)
        {
            FinishOpen(session);
        }
    }

    public void Subscribe(ICanvasSubscriber subscriber)
    {
        ArgumentNullException.ThrowIfNull(subscriber);
        lock (_gate)
        {
            var strokes = _strokes.Select(stroke => new StrokeSnapshot(stroke.Id, stroke.ToArray(), stroke.Done)).ToArray();
            if (subscriber.Deliver(CanvasUpdate.ForSnapshot(_epoch, strokes)))
            {
                _subscribers.Add(subscriber);
            }
        }
    }

    public void Unsubscribe(ICanvasSubscriber subscriber)
    {
        lock (_gate)
        {
            _subscribers.Remove(subscriber);
        }
    }

    public bool IsSubscribed(ICanvasSubscriber subscriber)
    {
        lock (_gate)
        {
            return _subscribers.Contains(subscriber);
        }
    }

    private void FinishOpen(CanvasSession session)
    {
        if (session.Open is { } open && open.Epoch == _epoch && !open.Done)
        {
            open.Done = true;
            Broadcast(CanvasUpdate.ForStroke(_epoch, open.Id, open.Count, [], true), session.Subscriber);
        }

        session.Open = null;
    }

    private bool MakeRoom(int count)
    {
        var node = _strokes.First;
        while (_points + count > _maxPoints && node is not null)
        {
            var next = node.Next;
            if (node.Value.Done)
            {
                _points -= node.Value.Count;
                _strokes.Remove(node);
            }

            node = next;
        }

        return _points + count <= _maxPoints;
    }

    private void Broadcast(CanvasUpdate update, ICanvasSubscriber? except)
    {
        List<ICanvasSubscriber>? dropped = null;
        foreach (var subscriber in _subscribers)
        {
            if (!ReferenceEquals(subscriber, except) && !subscriber.Deliver(update))
            {
                (dropped ??= []).Add(subscriber);
            }
        }

        if (dropped is not null)
        {
            _subscribers.ExceptWith(dropped);
        }
    }
}

    public const string Unknown = "unknown";

    public static string Key(IPAddress? address)
    {
        if (address is null)
        {
            return Unknown;
        }

        if (address.IsIPv4MappedToIPv6)
        {
            address = address.MapToIPv4();
        }

        if (address.AddressFamily != AddressFamily.InterNetworkV6)
        {
            return address.ToString();
        }

        Span<byte> bytes = stackalloc byte[16];
        address.TryWriteBytes(bytes, out _);
        bytes[8..].Clear();
        return new IPAddress(bytes) + "/64";
    }

using Microsoft.Extensions.Options;

namespace Chaos.Web.Infrastructure;

internal enum ConnectionAdmission
{
    Admitted,
    ClientFull,
    ServerFull,
}

internal sealed class ConnectionTracker(IOptions<ChaosOptions> options)
{
    private readonly Lock _gate = new();
    private readonly Dictionary<string, int> _perClient = new(StringComparer.Ordinal);
    private int _total;

    public int Total
    {
        get
        {
            lock (_gate)
            {
                return _total;
            }
        }
    }

    public int CountFor(string client)
    {
        lock (_gate)
        {
            return _perClient.GetValueOrDefault(client);
        }
    }

    public ConnectionAdmission TryAdmit(string client, out IDisposable? lease)
    {
        var limits = options.Value;
        lock (_gate)
        {
            if (_total >= limits.MaxConnections)
            {
                lease = null;
                return ConnectionAdmission.ServerFull;
            }

            var count = _perClient.GetValueOrDefault(client);
            if (count >= limits.MaxConnectionsPerClient)
            {
                lease = null;
                return ConnectionAdmission.ClientFull;
            }

            _perClient[client] = count + 1;
            _total++;
        }

        lease = new Lease(this, client);
        return ConnectionAdmission.Admitted;
    }

    private void Release(string client)
    {
        lock (_gate)
        {
            var count = _perClient.GetValueOrDefault(client) - 1;
            if (count > 0)
            {
                _perClient[client] = count;
            }
            else
            {
                _perClient.Remove(client);
            }

            _total--;
        }
    }

    private sealed class Lease(ConnectionTracker owner, string client) : IDisposable
    {
        private int _released;

        public void Dispose()
        {
            if (Interlocked.Exchange(ref _released, 1) == 0)
            {
                owner.Release(client);
            }
        }
    }
}

    public static IApplicationBuilder UseHubGuard(this IApplicationBuilder app)
    {
        ArgumentNullException.ThrowIfNull(app);
        var tracker = app.ApplicationServices.GetRequiredService<ConnectionTracker>();
        var options = app.ApplicationServices.GetRequiredService<IOptions<ChaosOptions>>();
        var logger = app.ApplicationServices.GetRequiredService<ILoggerFactory>().CreateLogger("Chaos.Web.HubGuard");

        return app.Use(async (context, next) =>
        {
            if (!context.Request.Path.StartsWithSegments(HubPath, out var remainder))

                return;

                return;

            if (remainder.HasValue)
            {
                await next(context);
                return;
            }

            if (!context.WebSockets.IsWebSocketRequest)
            {
                await RejectAsync(context, StatusCodes.Status400BadRequest, "Only WebSocket connections are accepted.");
                return;

            if (admission is not ConnectionAdmission.Admitted)

                if (admission is ConnectionAdmission.ServerFull)

                    ? StatusCodes.Status503ServiceUnavailable
                    : StatusCodes.Status429TooManyRequests;

                return;

            using (lease)

                await next(context);
            }

namespace Chaos.Web.Infrastructure;

internal sealed class KeyedTokenBuckets(double capacity, double perSecond, TimeProvider time, int maxKeys = 10_000)
{
    private readonly Dictionary<string, TokenBucket> _buckets = new(StringComparer.Ordinal);
    private readonly Lock _gate = new();

    public int Count
    {
        get
        {
            lock (_gate)
            {
                return _buckets.Count;
            }
        }
    }

    public bool TryTake(string key, double count = 1)
    {
        lock (_gate)
        {
            if (!_buckets.TryGetValue(key, out var bucket))
            {
                if (_buckets.Count >= maxKeys)
                {
                    Sweep();
                }

                bucket = new TokenBucket(capacity, perSecond, time);
                _buckets[key] = bucket;
            }

            return bucket.TryTake(count);
        }
    }

    private void Sweep()
    {
        foreach (var (key, bucket) in _buckets)
        {
            if (bucket.IsFull)
            {
                _buckets.Remove(key);
            }
        }

        if (_buckets.Count >= maxKeys)
        {
            _buckets.Clear();
        }
    }
}

    }

using System.Threading.Channels;

namespace Chaos.Web.Infrastructure;

internal sealed class Outbox<T> : IAsyncDisposable
{
    private readonly Channel<T> _channel;
    private readonly CancellationTokenSource _stop = new();
    private readonly Func<IReadOnlyList<T>, CancellationToken, Task> _send;
    private readonly int _maxBatch;
    private readonly TimeSpan _timeout;
    private readonly ILogger _logger;
    private readonly Task _pump;
    private volatile bool _faulted;

    public Outbox(int capacity, int maxBatch, TimeSpan timeout, Func<IReadOnlyList<T>, CancellationToken, Task> send, ILogger logger)
    {
        _channel = Channel.CreateBounded<T>(new BoundedChannelOptions(capacity)
        {
            SingleReader = true,
            FullMode = BoundedChannelFullMode.Wait,
        });
        _maxBatch = maxBatch;
        _timeout = timeout;
        _send = send;
        _logger = logger;
        _pump = Task.Run(PumpAsync);
    }

    public bool IsFaulted => _faulted;

    public bool TryPost(T item) => !_faulted && _channel.Writer.TryWrite(item);

    public async ValueTask DisposeAsync()
    {
        _channel.Writer.TryComplete();
        await _stop.CancelAsync().ConfigureAwait(false);
        await _pump.ConfigureAwait(false);
        _stop.Dispose();
    }

    private async Task PumpAsync()
    {
        var batch = new List<T>(_maxBatch);
        try
        {
            while (await _channel.Reader.WaitToReadAsync(_stop.Token).ConfigureAwait(false))
            {
                while (batch.Count < _maxBatch && _channel.Reader.TryRead(out var item))
                {
                    batch.Add(item);
                }

                using var timeout = CancellationTokenSource.CreateLinkedTokenSource(_stop.Token);
                timeout.CancelAfter(_timeout);
                await _send([.. batch], timeout.Token).ConfigureAwait(false);
                batch.Clear();
            }
        }
        catch (OperationCanceledException) when (_stop.IsCancellationRequested)
        {
        }
        catch (Exception exception)
        {
            _faulted = true;
            _channel.Writer.TryComplete();
            OutboxLog.SendFailed(_logger, exception);
        }
    }
}

{
    [LoggerMessage(Level = LogLevel.Debug, Message = "Realtime delivery stopped")]
    public static partial void SendFailed(ILogger logger, Exception exception);
}

internal sealed class TokenBucket
{
    private readonly double _capacity;
    private readonly double _perSecond;
    private readonly TimeProvider _time;
    private double _tokens;
    private long _stamp;

    public TokenBucket(double capacity, double perSecond, TimeProvider time)
    {
        ArgumentNullException.ThrowIfNull(time);

        _perSecond = perSecond;
        _time = time;
        _tokens = capacity;
        _stamp = time.GetTimestamp();
    }

    public bool IsFull
    {
        get
        {
            Refill();
            return _tokens >= _capacity;
        }
    }

    public bool TryTake(double count = 1)
    {
        Refill();
        if (_tokens < count)
        {
            return false;
        }

        _tokens -= count;
        return true;
    }

    private void Refill()
    {
        var now = _time.GetTimestamp();
        var elapsed = _time.GetElapsedTime(_stamp, now).TotalSeconds;
        _stamp = now;
        _tokens = Math.Min(_capacity, _tokens + (elapsed * _perSecond));
    }
}

using Chaos.Web.Infrastructure;
using Microsoft.Extensions.Options;

namespace Chaos.Web.Messages;

internal sealed class BoardService
{
    public const int MaxOffers = 50;
    public const int RepeatWindow = 10;

    private readonly TimeProvider _time;
    private readonly KeyedTokenBuckets _posts;
    private readonly Lock _gate = new();
    private readonly HashSet<IBoardSubscriber> _subscribers = [];
    private BoardMessage[] _messages = [];
    private long _version;

    public BoardService(TimeProvider time, IOptions<ChaosOptions> options)
    {
        ArgumentNullException.ThrowIfNull(time);
        ArgumentNullException.ThrowIfNull(options);
        var limits = options.Value;
        _time = time;
        Capacity = limits.BoardCapacity;
        _posts = new KeyedTokenBuckets(limits.PostBurst, limits.PostsPerSecond, time);
        StartedAt = time.GetUtcNow();
    }

    public int Capacity { get; }

    public DateTimeOffset StartedAt { get; }

    public IReadOnlyList<BoardMessage> Messages => Volatile.Read(ref _messages);

    public long Version
    {
        get
        {
            lock (_gate)
            {
                return _version;
            }
        }
    }

    public PostResult Post(string? input, string client)
    {
        var text = MessageText.Normalize(input);
        if (text.Length == 0)
        {
            return PostResult.Empty;
        }

        if (!_posts.TryTake(client))
        {
            return PostResult.TooFast;
        }

        lock (_gate)
        {
            var window = Math.Min(RepeatWindow, _messages.Length);
            for (var i = 0; i < window; i++)
            {
                if (string.Equals(_messages[i].Text, text, StringComparison.Ordinal))
                {
                    return PostResult.Repeat;
                }
            }

            Merge([new BoardMessage(Guid.CreateVersion7(_time.GetUtcNow()), text)]);
        }

        return PostResult.Accepted;
    }

    public int Offer(IEnumerable<BoardMessage> offered)
    {
        ArgumentNullException.ThrowIfNull(offered);
        var now = _time.GetUtcNow();
        var valid = new List<BoardMessage>();
        foreach (var message in offered.Take(MaxOffers))
        {
            if (IsAcceptable(message, now))
            {
                valid.Add(message);
            }
        }

        if (valid.Count == 0)
        {
            return 0;
        }

        lock (_gate)
        {
            return Merge(valid);
        }
    }

        {
            _subscribers.Remove(subscriber);

    {

        if (change is null)

            return 0;

        var previous = _version;
        _version++;
        Volatile.Write(ref _messages, change.Next);
        Broadcast(BoardUpdate.Delta(_version, previous, change.Added, change.Removed));
        return change.Added.Length;
    }

    {
        List<IBoardSubscriber>? dropped = null;
        foreach (var subscriber in _subscribers)
        {
            if (!subscriber.Deliver(update))
            {
                (dropped ??= []).Add(subscriber);
            }
        }

        if (dropped is not null)
        {
            _subscribers.ExceptWith(dropped);
        }
    }

    public const int MaxLength = 500;

    public static string Normalize(string? input)
    {
        if (string.IsNullOrWhiteSpace(input))
        {
            return "";
        }

        var text = string.Concat(input.ReplaceLineEndings("\n").Where(c => c == '\n' || !char.IsControl(c)));
        text = ExtraBlankLines().Replace(text, "\n\n").Trim();

        if (text.Length > MaxLength)
        {
            var cut = 0;
            while (cut < text.Length)
            {
                var next = StringInfo.GetNextTextElementLength(text, cut);
                if (cut + next > MaxLength)
                {
                    break;
                }

                cut += next;
            }

            text = text[..cut].TrimEnd();
        }

        return text.Any(IsVisible) ? text : "";
    }

    public static bool IsNormalized(string? text) =>
        !string.IsNullOrEmpty(text) && string.Equals(Normalize(text), text, StringComparison.Ordinal);

    private static bool IsVisible(char c) =>
        !char.IsWhiteSpace(c) && char.GetUnicodeCategory(c) != UnicodeCategory.Format;

    private static partial Regex ExtraBlankLines();

internal sealed record WindowChange(BoardMessage[] Next, BoardMessage[] Added, Guid[] Removed);

internal static class MessageWindow
{
    public static WindowChange? Merge(BoardMessage[] current, IEnumerable<BoardMessage> candidates, int capacity)
    {
        ArgumentNullException.ThrowIfNull(current);
        ArgumentNullException.ThrowIfNull(candidates);
        var known = new HashSet<Guid>(current.Length);
        foreach (var message in current)
        {
            known.Add(message.Id);
        }

        var next = current
            .Concat(candidates.Where(message => !known.Contains(message.Id)).DistinctBy(message => message.Id))
            .OrderByDescending(message => message.Id)
            .Take(capacity)
            .ToArray();
        var added = next.Where(message => !known.Contains(message.Id)).ToArray();
        if (added.Length == 0)
        {
            return null;
        }

        var kept = next.Select(message => message.Id).ToHashSet();
        var removed = current.Where(message => !kept.Contains(message.Id)).Select(message => message.Id).ToArray();
        return new WindowChange(next, added, removed);
    }

    public static bool IsRestorable(Guid id, DateTimeOffset now, DateTimeOffset startedAt)
    {
        if (!Uuid7.IsValid(id))
        {
            return false;
        }

        var at = Uuid7.Timestamp(id);
        return at <= now && at < startedAt;
    }
}

using System.Diagnostics.CodeAnalysis;
using System.Security.Cryptography;

namespace Chaos.Web.Slots;

internal static class SlotRules
{
    public const int Length = 5;
    public const string Symbols = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

    public static string Draw() => RandomNumberGenerator.GetString(Symbols, Length);

    public static bool IsValid([NotNullWhen(true)] string? text)
    {
        if (text is null || text.Length != Length)
        {
            return false;
        }

        foreach (var c in text)
        {
            if (!char.IsAsciiDigit(c) && !char.IsAsciiLetterUpper(c))
            {
                return false;
            }
        }

        return true;
    }

    public static SlotWin Classify(string? text)
    {
        if (!IsValid(text))
        {
            return SlotWin.None;
        }

        var most = text.GroupBy(c => c).Max(group => group.Count());
        if (most >= 5)
        {
            return SlotWin.FiveOfAKind;
        }

        if (most == 4)
        {
            return SlotWin.FourOfAKind;
        }

        if (most == 3)
        {
            return SlotWin.ThreeOfAKind;
        }

        if (IsOrdered(text, 1))
        {
            return SlotWin.StraightUp;
        }

        return IsOrdered(text, -1) ? SlotWin.StraightDown : SlotWin.None;
    }

    public static bool[] Hits(string? text)
    {
        var hits = new bool[Length];
        if (!IsValid(text))
        {
            return hits;
        }

        var win = Classify(text);
        if (win is SlotWin.None)
        {
            return hits;
        }

        if (win is SlotWin.StraightUp or SlotWin.StraightDown)
        {
            Array.Fill(hits, true);
            return hits;
        }

        var top = text.GroupBy(c => c).MaxBy(group => group.Count())!.Key;
        for (var i = 0; i < Length; i++)
        {
            hits[i] = text[i] == top;
        }

        return hits;
    }

    public static string Label(SlotWin win) => win switch
    {
        SlotWin.ThreeOfAKind => "Three of a kind",
        SlotWin.FourOfAKind => "Four of a kind",
        SlotWin.FiveOfAKind => "Five of a kind",
        SlotWin.StraightUp => "Straight up",
        SlotWin.StraightDown => "Straight down",
        _ => "",
    };

    public static char Above(char symbol) => Symbols[(Symbols.IndexOf(symbol, StringComparison.Ordinal) + 1) % Symbols.Length];

    public static char Below(char symbol) => Symbols[(Symbols.IndexOf(symbol, StringComparison.Ordinal) + Symbols.Length - 1) % Symbols.Length];

    private static bool IsOrdered(string text, int direction)
    {
        for (var i = 1; i < text.Length; i++)
        {
            if ((text[i] - text[i - 1]) * direction <= 0)
            {
                return false;
            }
        }

        return true;
    }
}

    private long _version;
    private Guid _spinId;
    private long? _spinStarted;

    public SlotService(TimeProvider time, IOptions<ChaosOptions> options)
    {
        ArgumentNullException.ThrowIfNull(time);
        ArgumentNullException.ThrowIfNull(options);
        var limits = options.Value;
        _time = time;
        Capacity = limits.SlotCapacity;
        SpinTime = TimeSpan.FromMilliseconds(limits.SpinMilliseconds);
        _presses = new KeyedTokenBuckets(limits.PressBurst, limits.PressesPerSecond, time);

    public int Capacity { get; }

    public TimeSpan SpinTime { get; }

    public DateTimeOffset StartedAt { get; }

    public IReadOnlyList<BoardMessage> Messages => Volatile.Read(ref _messages);

    public SlotSpin? Spinning
    {
        get
        {
            lock (_gate)
            {
                return CurrentSpin(_time.GetTimestamp());
            }
        }
    }

    public SlotPress Press(string client)
    {
        lock (_gate)
        {
            var now = _time.GetTimestamp();
            if (CurrentSpin(now) is not null)
            {
                return SlotPress.Busy;
            }

            if (!_presses.TryTake(client))
            {
                return SlotPress.TooFast;
            }

            var message = new BoardMessage(Guid.CreateVersion7(_time.GetUtcNow()), SlotRules.Draw());
            _spinId = message.Id;
            _spinStarted = now;
            Merge([message], new SlotSpin(message.Id, Milliseconds(SpinTime)));
            return SlotPress.Started(message.Id);
        }
    }

    public int Offer(IEnumerable<BoardMessage> offered)
    {
        ArgumentNullException.ThrowIfNull(offered);
        var now = _time.GetUtcNow();
        var valid = offered
            .Take(MaxOffers)
            .Where(message => message is not null && MessageWindow.IsRestorable(message.Id, now, StartedAt) && SlotRules.IsValid(message.Text))
            .ToList();
        if (valid.Count == 0)
        {
            return 0;
        }

        lock (_gate)
        {
            return Merge(valid, null);
        }
    }

    public void Subscribe(ISlotSubscriber subscriber)
    {
        ArgumentNullException.ThrowIfNull(subscriber);
        lock (_gate)
        {
            if (subscriber.Deliver(SlotUpdate.Snapshot(_version, _messages, CurrentSpin(_time.GetTimestamp()))))
            {
                _subscribers.Add(subscriber);
            }
        }
    }

    public void Unsubscribe(ISlotSubscriber subscriber)
    {
        lock (_gate)
        {
            _subscribers.Remove(subscriber);
        }
    }

    public bool IsSubscribed(ISlotSubscriber subscriber)
    {
        lock (_gate)
        {
            return _subscribers.Contains(subscriber);
        }
    }

    private static int Milliseconds(TimeSpan span) => (int)Math.Ceiling(span.TotalMilliseconds);

    private SlotSpin? CurrentSpin(long now)
    {
        if (_spinStarted is not { } started)
        {
            return null;
        }

        var remaining = SpinTime - _time.GetElapsedTime(started, now);
        return remaining > TimeSpan.Zero ? new SlotSpin(_spinId, Milliseconds(remaining)) : null;
    }

    private int Merge(IReadOnlyCollection<BoardMessage> candidates, SlotSpin? spin)
    {
        var change = MessageWindow.Merge(_messages, candidates, Capacity);
        if (change is null)

            return 0;
        }

        _version++;
        Volatile.Write(ref _messages, change.Next);
        Broadcast(SlotUpdate.Delta(_version, previous, change.Added, change.Removed, spin));
        return change.Added.Length;
    }

        foreach (var subscriber in _subscribers)
        {
            if (!subscriber.Deliver(update))
            {
                (dropped ??= []).Add(subscriber);
            }
        }

        if (dropped is not null)
        {
            _subscribers.ExceptWith(dropped);
        }
    }
